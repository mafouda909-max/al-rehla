# مشروع الرحلة MVP

نسخة أولية ثابتة HTML/CSS/JS لمنصة عروض وطلبات سفر.

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## الصفحات
- `index.html` الصفحة الرئيسية
- `tickets.html` عروض التذاكر
- `visas.html` عروض التأشيرات
- `request.html` اطلب عرض خاص
- `join-agent.html` انضم كوكيل
- `agent.html` ملف الوكيل
- `offer-details.html` تفاصيل العرض
- `admin.html` لوحة إدارة شكلية

## تعديل البيانات
العروض والوكلاء موجودين في:
`data/offers.js`

## ملاحظات
هذه نسخة Prototype بدون قاعدة بيانات. الفورمات تعرض رسالة نجاح فقط ولا ترسل بيانات حقيقية.
